# 聊天与文件引用

**Chat** 按钮位于应用顶部栏右上角。

## 选择 Agent 与模型

聊天框左侧依次是 **Agent**、**Model**、**Mode** 三个选择器。

- **Agent** 决定对话的后端。**Nest Agent** 使用 Settings 里配置的模型；
  **Claude** 在 Settings 中开启并连接成功后，会通过本机 Claude CLI 进行对话。
  该选择在首次发送消息时生效并固定；之后切换 Agent 会新建会话，未发送的草稿
  会一并带过去。
- **Model** 显示将要使用的模型：Nest 显示配置的 API 模型；Claude 显示 CLI
  当前生效的模型（标注 `(default)`）以及你在 Settings 里列出的自定义模型。
- **Mode** 即下文的 **Ask** / **Agent** 模式。

## 在已启用知识中提问

没有引用的提示词会搜索所有已启用知识包。请说明想要的结果、受众和格式。

## 使用 `@` 聚焦

输入 `@`，选择文件或文件夹，即可将检索范围限定在该引用上，可组合多个引用。

```text
@getting-started-zh-cn/guides/编辑与源代码管理.md
请给我一份发布前审查修改的检查清单。
```

## 检查引用来源

回答不完整或范围过大时，打开引用核对来源，再重新描述问题或缩小 `@` 引用范围。

## 使用建议

1. 只启用相关知识包。
2. 每次提出一个明确任务。
3. 说明受众与输出格式。
4. 根据引用核对重要内容。
